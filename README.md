# 自动弹奏钢琴 🐈

纯前端单页应用，无需构建、无需服务器，浏览器直接打开 `index.html` 即可使用。

## 文件结构

所有文件平铺在同一目录下，没有子目录：

```
index.html      页面结构（键盘、控制面板、选曲弹窗等 DOM）
styles.css      全部样式
core.js         曲库加载/保存/远程合并 + 88 键键盘构建 + 键盘平滑滚动
audio-midi.js   合成钢琴音频引擎（踏板、混响）+ MIDI 文件解析与播放调度
playback.js     自动演奏调度（简谱/和弦模式）+ 选曲、自定义谱、导入导出、曲库列表渲染 + 停止/退出与控制面板事件绑定
listen.js       听歌辨谱（本地麦克风采集 + 自相关基频检测 + 调号识别，全程离线不联网）
ui-extras.js    选曲弹窗 Tab 切换、中英文曲名显示、季节飘落粒子特效、横竖屏自动检测
```

`index.html` 按上表顺序以普通 `<script src="...">` 标签加载各文件（不使用
`type="module"`），因此可以直接双击 `index.html` 用 `file://` 协议打开，无需
起 HTTP 服务器。多个 `<script>` 之间共享同一个全局作用域，所以各文件里的
顶层变量、函数可以互相调用。

**下载/部署时请把 `index.html`、`styles.css` 和 5 个 `.js` 文件放在同一个目录下**，
不要分子目录，否则脚本会 404。

## 主要功能

- 88 键钢琴键盘，支持自动演奏、力度表情渐强、延音踏板、混响、移调、变速
- 曲库：简谱（音名+和弦）与导入的 MIDI 曲目共存，可增删、导入导出 JSON
- 启动时自动从远程曲库地址拉取并合并曲目（同 id 覆盖本地、新 id 追加）：
  ```
  https://totp99.github.io/source/piano/auto-piano-library.json
  ```
- 听歌辨谱：麦克风哼唱 → 自相关基频检测 → 写入简谱输入框
- 春/夏/秋/冬四套飘落粒子特效，可通过右下角按钮循环切换
- 横屏下键盘自动缩放到整屏可见，无需横向滚动

## 本地曲库存储

曲库以 `localStorage`（key: `autoPiano.songLibrary.v2`）保存在浏览器本地，
清除浏览器数据会导致自定义/导入的曲目丢失，建议重要曲目用「导出全部」
功能导出为 JSON 备份。
